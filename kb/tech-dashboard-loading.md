# Dashboard not loading or slow

First check the status page for incidents. Then: hard-refresh (Ctrl/Cmd+Shift+R), clear cache and cookies, disable browser extensions, and try a private window. Supported browsers: latest two versions of Chrome, Firefox, Safari and Edge. If the dashboard shows a blank page, include the browser console error and the `x-request-id` when contacting support.
