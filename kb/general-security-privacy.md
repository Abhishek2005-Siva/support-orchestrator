# Security and privacy

Orbit encrypts data in transit (TLS 1.2+) and at rest (AES-256). We are SOC 2 Type II audited and GDPR compliant. Support staff and assistants will **never ask for your password, full card number, CVV or API key** in chat. Report suspected account compromise immediately: we can lock the account and revoke all API keys. Security reports: security@orbit.example.
