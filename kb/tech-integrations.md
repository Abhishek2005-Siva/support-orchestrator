# Slack, Zapier and other integrations

Connect integrations under Dashboard > Integrations. The Slack integration needs the Admin role in both Orbit and Slack; it posts alerts to a channel you choose. Zapier uses an API key created with the "integration" scope. If an integration shows "disconnected", re-authorize it; tokens expire after 90 days of inactivity.
