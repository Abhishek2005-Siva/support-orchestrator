# Exporting your data

Dashboard > Settings > Data export creates a CSV or JSON export. Exports run asynchronously and a download link is emailed when ready (usually under 15 minutes). The link is valid for 7 days. Maximum export size is **2 GB** per request; for larger datasets filter by date range and export in several parts, or use the Export API. Export is read-only and does not delete data.
