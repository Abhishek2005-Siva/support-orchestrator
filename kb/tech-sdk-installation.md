# SDK installation and requirements

Python: `pip install orbit-sdk` (Python 3.9 or newer). Node.js: `npm install @orbit/sdk` (Node 18 or newer). Initialise with `Orbit(api_key=...)`. If installation fails, upgrade pip (`pip install --upgrade pip`) or use a clean virtual environment. Pin the SDK version in production. SDK version 2.x is required for webhooks signature helpers.
