Runs the chosen scenarios one after another, then waits between runs. It runs inside this browser tab: closing the tab stops it. Every run sends real messages through the live system and uses model calls (about 5 per scenario).

How it works

  1. Input guard cleans the message, masks card numbers and secrets, blocks injection and SQL attacks (no AI, milliseconds).
  2. Dispatcher decides what you need, how urgent and upset you are; legal, security and "get me a human" always escalate.
  3. Specialist agents (billing, technical, general) work in parallel using real tools that can only see your account.
  4. Policy layer decides money questions in code (refund eligibility, approval limits), never the AI.
  5. Validator re-checks every amount, date, id and claim against the evidence; unsupported answers are revised or held.
  6. Human desk handles escalations and approvals; the graph pauses until a person decides.

Synthetic data. The free model endpoint makes answers take several seconds.
